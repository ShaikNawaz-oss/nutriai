# 🥗 NutriAI

AI-Powered Nutrition & Smart Grocery Assistant.

## Features

- Personalized meal planning
- 1–7 day meal plans
- Dietary preferences
- Nutrition goals
- Calorie targets
- Protein targets
- Nutrition scoring
- Smart grocery list
- Budget analysis
- Food waste reduction

## Requirements

- Python 3.9 or newer
- Streamlit

## How to Run

Open a terminal inside the project folder.

Install the required package:

pip install -r requirements.txt

Run the application:

streamlit run app.py

The application will open in your web browser.

## Note

NutriAI provides general nutrition suggestions for informational purposes only and is not a substitute for professional medical or dietary advice.
